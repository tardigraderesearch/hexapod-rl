# Software Lineage

ARI did not begin as a robot. The public story starts with a local assistant, then grows into a persistent software system, and only later expands into embodied robotics.

## June 2025: SARA

In June 2025, SARA began as a custom Python assistant wrapper built before Hermes Agent existed in this project. SARA is a historical milestone, but no source survives in this public repository.

That absence reflects the project history: SARA was no longer retained after the project moved from the older assistant wrapper to ARI. Because the source no longer exists, this portfolio does not fabricate screenshots, code excerpts, metrics, detailed capabilities, or reconstructed implementation history for SARA.

The accurate claim is narrower and more useful: SARA established the first local-assistant phase and created lessons that informed ARI.

## ARI Software System

SARA's lessons evolved into ARI, a persistent assistant grounded in an Obsidian vault. The public repository describes this only at a sanitized architectural level: local context grounding, persistent memory, tool use, messaging, voice interaction, and bounded coding delegation.

ARI later integrated with Hermes Agent as the assistant system matured. The integration helped move ARI from a one-off wrapper into a broader orchestration layer for memory, tool use, communication, voice, and controlled development assistance.

This public snapshot does not expose vault content, vault paths, message IDs, endpoints, credentials, private prompts, operational configuration, or personal data.

## ARI Physical Robot

The 18-DOF hexapod came third. It extended the software-assistant program into a physical robotics platform with mechanical design, CAD/fabrication decisions, electronics integration, ESP32-class servo control, deterministic gait work, Isaac simulation, observation/evaluator design, and embodied-autonomy research.

The chronology matters:

1. June 2025: SARA established the local-assistant starting point.
2. ARI software system: persistent assistant architecture grew around a knowledge workflow and Hermes Agent integration.
3. ARI robot: the assistant program expanded into an embodied robotics project.

The current physical robot has deterministic scripted hardware gait evidence. Learned locomotion evidence in this repository remains simulator-only unless explicitly labeled otherwise.
